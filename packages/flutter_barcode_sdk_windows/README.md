# flutter_barcode_sdk_windows

Platform implementation of [flutter_barcode_sdk](https://pub.dev/packages/flutter_barcode_sdk).

This package provides the native implementation of the `flutter_barcode_sdk`
federated plugin. It is automatically endorsed by the app-facing package
and should not be added directly to pubspec.yaml in most cases.

## Usage

This package is not intended for direct use by app developers.
